# 访谈转录质性分析工作台

用于访谈转录文本的质性编码（qualitative coding）Web 工作台：按字符区间给文本片段添加**可重叠**编码，实时检测同名与嵌套冲突，并提供合并 / 拆分 / 保留边界三种决策。数据落盘 SQLite，刷新、重启均可恢复。

技术栈：React 18 + Vite · FastAPI · SQLite · Docker Compose

## 一键启动

```bash
docker compose up --build
```

## 访问地址

| 入口 | 地址 |
| --- | --- |
| Web 工作台 | http://localhost:8080 |
| 后端 API（Swagger 文档） | http://localhost:8000/docs |
| 健康检查 | http://localhost:8000/api/health |

数据保存在名为 `qual-data` 的 Docker 卷中（容器内路径 `/data/app.db`），删除容器不丢数据。

## 功能说明

- **区间编码**：在文本上**拖选**，或在表单中直接输入半开区间 `[起始, 结束)`，选择既有编码或新建编码即可添加标注；支持对同一文本叠加多个编码（重叠高亮以渐变条带呈现）。
- **冲突实时检测**：提交前先调用 `POST /api/codings/preview` 检测——
  - **同名冲突**：相同编码的区间相互重叠；
  - **嵌套冲突**：不同编码的区间互相包含（含两个方向）。
- **三种决策**：
  - **合并 merge**：同名且重叠/相邻的编码合并为一个连续区间（传递闭包）；
  - **拆分 split**：沿新区间边界拆分外层编码；若新区间包含他者，则新区间自身绕开拆分；
  - **保留边界 keep**：不做调整，重叠 / 嵌套共存。
- **编辑与删除**：侧栏标注列表支持定位（滚动 + 闪烁）、编辑（改区间或改编码，同样走冲突检测）、删除。
- **检索批量编码**：右侧「检索批量编码」面板输入**字面关键词**（非正则），`GET /api/documents/{id}/search` 返回当前文档全部命中的稳定半开区间与前后文，**彼此重叠的命中也一并返回**（如 `aa` 在 `aaa` 中命中 `[0,2)` 与 `[1,3)`）；前端逐项勾选或全选，选择一个**既有编码**后批量提交——
  - `POST /api/codings/batch` 在**单个事务**中先校验全部区间，任一非法（`end <= start` 或超出文本长度）即整批回滚、不落库；
  - 校验通过后逐项写入：与既有标注**完全相同**（同编码、同区间）的项记为**跳过**，其余按 **keep（保留边界）** 原样写入，不做合并 / 拆分；
  - 返回**新增与跳过明细**（跳过项附带既有标注 id），提交成功后正文高亮与编码计数随即刷新；单条标注的冲突检测与决策流程不受影响。
- **编码筛选**：编码本复选框控制文本高亮、标注列表、共现矩阵与说话人分析的显示范围。
- **编码共现视图**：正文区顶部切换到「编码共现」标签，按当前文档展示编码两两关系矩阵——
  - 计算口径：先分别**合并同一编码自身重叠或相邻（首尾相接）的半开区间**，再对每对编码求区间交集，保证共享字符不被重复计数；
  - 矩阵可在**共现覆盖字符数**（交集各段长度之和）与**共现片段数**（交集被编码边界切成的段数）两种指标间切换，单元格按数值相对最大值**深浅着色**；对角线灰色显示该编码自身合并后的覆盖，仅供参考；
  - 点击非零单元格列出对应**交集片段及原文摘录**，点击片段自动切回正文、滚动并闪烁定位高亮；
  - 编码筛选变化后矩阵与片段明细同步更新；无共现或未勾选编码时给出明确空状态。
  - 对应 `GET /api/documents/{id}/cooccurrence?codes=…`。
- **说话人分析视图**：正文区顶部切换到「说话人分析」标签，按文档中形如「说话人：内容」的发言段落（行首标签 + 全角/半角冒号，段落延伸至下一说话人行首）统计每位说话人——
  - 表格列出每位说话人的**发言段落数、文本长度、总覆盖（选中编码并集）及各编码覆盖字符数与覆盖率**（覆盖率 = 覆盖字符数 ÷ 文本长度）；文首无法识别说话人的文本归入**未标注说话人**；
  - 计算口径：同一编码的重叠标注**先合并再裁剪到发言段落**，共享字符不重复计数；全部发言段落与未标注部分恰好覆盖整篇文档；
  - 顶部**说话人筛选**复选框控制表格行显示，底部给出当前显示说话人的合计行；
  - 点击说话人名查看其发言段落，点击覆盖统计单元格查看覆盖片段与原文摘录，点击片段自动切回正文、滚动并闪烁定位高亮；
  - 编码筛选变化后统计列同步更新；未识别到发言段落或未选择编码时给出明确空状态。
  - 对应 `GET /api/documents/{id}/speakers?codes=1,2`（`codes` 为逗号分隔，缺省统计全部编码）。
- **跨文档分布对比视图**：正文区顶部切换到「分布对比」标签，对**全部文档**按所选编码汇总**标注字符数、标注段数与占文档长度比例**——
  - 表格行为编码、列为文档（按文档标题稳定排序），同一编码在各文档并列对比；单元格按行内最高占比**深浅着色**，并显示相对行内最高值的**差异百分比**；
  - 计算口径：同一编码在每篇文档内先合并重叠/相邻区间再统计，共享字符不重复计数；占比 = 标注字符数 ÷ 文档长度；
  - 顶部**文档筛选**复选框控制列显示，编码筛选与其它视图联动；
  - 点击非零单元格自动**切换到该文档正文**、滚动并闪烁定位**首个对应片段**；
  - 后端在**单一快照**中计算并返回**缺失编码**（全部文档均无标注）与**空文档**（没有所选编码标注）提示，不修改任何原标注。
  - 对应 `GET /api/code-distribution?codes=1,2`（`codes` 为逗号分隔，缺省统计全部编码）。
- **覆盖缺口视图**：正文区顶部切换到「覆盖缺口」标签，按当前文档与编码筛选列出**未被所选编码覆盖的连续文本区间**——
  - 计算口径：后端先把所选编码的半开标注区间**合并重叠/相邻区间**为并集，再对 `[0, 全文长度)` 求补集；**文首、文尾与零标注**（全文即一个缺口）场景均正确保留；
  - 每个缺口返回**起止位置、长度与原文摘录**；顶部摘要给出已覆盖字符数与覆盖率；
  - 前端提供**最小缺口长度**筛选（本地过滤，不重新请求）与**上一处 / 下一处**循环导航，点击缺口或导航均自动切回正文、滚动并闪烁定位；
  - 「带入编码表单」把整段缺口区间填入右侧编码表单（等同拖选效果），提交仍走原有**冲突预览**流程；
  - 编码筛选或标注变化后缺口列表同步刷新；所选编码并集覆盖全文时给出**「已全覆盖」**空状态。
  - 对应 `GET /api/documents/{id}/gaps?codes=1,2`（`codes` 为逗号分隔，缺省统计全部编码）。
- **编码流转视图**：正文区顶部切换到「编码流转」标签，按当前文档展示**相邻编码状态的有向转移**——
  - 计算口径：后端把所选编码的**全部标注起止边界**切成原子区间，以**覆盖编码集合**表示区间状态；**跳过无编码区间**并**合并相邻同状态区间**（被无编码间隔分开的同状态区间不合并），再按文档顺序统计相邻状态的有向转移次数；
  - 每次转移记录**来源区间、目标区间与中间距离**（目标起点 − 来源终点，0 表示首尾相接），并按（来源状态 → 目标状态）聚合计数，列表按次数降序排列；
  - 前端支持**最小次数**与**最大间距**筛选（本地过滤，不重新请求）；展开条目查看每次转移的来源 / 目标**原文上下文**，点击实例自动切回正文、滚动并**闪烁定位来源起点到目标终点的整个跨度**；
  - 编码筛选或标注变化后转移列表同步刷新；**零标注**（无状态区间）与**无转移**（仅一段状态区间）时给出明确空状态。
  - 对应 `GET /api/documents/{id}/transitions?codes=1,2`（`codes` 为逗号分隔，缺省统计全部编码）。
- **JSON 导出**：顶栏「导出 JSON」下载当前文档的完整编码结果（含每条标注的区间、原文切片与文档内容指纹 `fingerprint`），对应 `GET /api/documents/{id}/export`。
- **标注包导入**：顶栏「导入标注包」可**粘贴**导出 JSON 文本或**选择 `.json` 文件**，把另一份（或此前导出的）编码结果导入**当前文档**——
  - **编码按名称映射**：以编码**名称**对齐当前编码本（忽略导出文件中的编码 id，避免不同库 id 错位）；当前编码本中没有同名编码的条目标记为**未知编码**，需先在编码本新建同名编码再导入；
  - **校验内容指纹**：导出包含 `sha256` 内容指纹，指纹与当前文档不一致直接阻断（旧版无指纹导出退化为「文档长度 + 逐条原文切片」校验并给出提示）；同时逐条校验**区间边界**（整数、`start < end`、不超出文本长度）与**原文切片**是否与当前文档一致，区间错位会被标出；
  - **重复项识别**：与当前文档既有标注完全相同（同编码、同区间）记为跳过（附既有标注 id），标注包内部的重复条目同样跳过；
  - **预检明细**：确认前先展示**新增 / 跳过 / 未知编码 / 非法条目**四类明细与计数；新增项若与既有标注同名重叠或嵌套，会列出**冲突明细**（导入按 keep 保留边界共存，不做合并 / 拆分）；存在任一阻断项时确认按钮禁用；
  - **单事务落库**：确认后在**单个事务**内重跑全部校验再写入，任一校验失败（指纹不一致、非法区间 / 切片、未知编码）整批回滚、**不落库**；
  - **定位新增结果**：导入成功后结果面板列出全部新增标注，点击「定位」（或「定位第一条新增」）自动切回正文、滚动并闪烁高亮。
  - 对应 `POST /api/documents/{id}/import/preview`（预检，不落库）与 `POST /api/documents/{id}/import`（确认导入，单事务）。
- **文档版本迁移**：顶栏「文档版本迁移」提交当前文档的**新正文**，服务依据字符级文本差异把旧标注区间映射到新位置——
  - **唯一匹配自动保留**：旧标注原文在新正文中恰好出现一次时自动定位（插入 / 删除其它内容导致的整体偏移随之校正）；
  - **待确认**：①**多重匹配**（原文出现多次）列出全部候选位置及各自新上下文，并按差异对齐标记默认候选；②**内容改动**（原文字句被增删修改、但足量字符仍可对齐）给出覆盖首尾存活字符的建议区间；③**文本删除**（原文被删除）给出删除位置锚点；三类均可在对话框内嵌的**新正文预览中拖选手选**新区间或放弃该标注；
  - **失配**：旧位置被等量的新内容替换、无法可靠映射的标记载为失配，展示旧上下文与替换后的新文本，确认迁移时丢弃；
  - **预览 / 确认两段式**：预检（不落库）列出**保留、待确认、失配**三类明细及新旧上下文与候选定位；确认时校验**原文内容指纹（sha256）**与全部待确认决策（remap 区间必须满足 `0 <= start < end <= 新正文长度`），在**单事务**中更新正文与全部标注（保留项 / 重指定项更新区间并保留原 id，放弃项 / 失配项删除），指纹不一致、缺少决策或区间非法均返回 422 并**整体回滚、不落库**；取消或关闭对话框则原文档完全不变。
  - 对应 `POST /api/documents/{id}/migration/preview`（预检，不落库）与 `POST /api/documents/{id}/migration/commit`（确认迁移，单事务）。
- **标注抽样复核**：正文区顶部切换到「标注复核」标签，为当前文档**勾选编码并设置每种编码的抽样数量**，系统按**文档内容指纹（sha256）与标注 id 稳定抽取**待复核标注——
  - **稳定抽样**：每条标注的排序键为 `sha256(文档指纹 | 编码 id | 标注 id)`，按编码分组后各取前 N 条；只要文档内容与标注集合不变，反复生成、刷新页面甚至重启服务，抽到的标注与顺序都完全一致；抽样数量超过该编码标注数时抽取全部；
  - **逐条复核**：队列展示每条抽样标注的**编码、区间、原文与前后文**，可标记**通过 / 需修订**并填写**备注**（也可重置为待处理），顶部实时统计**待处理 / 通过 / 需修订**数量，并可按状态筛选；
  - **定位正文**：每条标注提供「定位正文」，点击切回正文并滚动闪烁高亮对应区间；
  - **过期与重生成**：批次生成时锁定文档指纹与标注集合指纹；之后若**文档正文变化**（编辑 / 版本迁移）或**标注变化**（新增 / 删除 / 改区间 / 改编码），批次自动标记为**已过期**（区分两种原因），队列仍可查看但复核操作暂停，提示重新生成；重新生成按最新文档与标注重新稳定抽样并清空此前结论，也可直接删除批次；
  - 抽样设置、复核结论与处理时间均**持久化在 SQLite**（`review_batches` / `review_batch_codes` / `review_items` 三张表），刷新、重启不丢失；每篇文档至多保留一个批次。
  - 对应 `GET/POST/DELETE /api/documents/{id}/review` 与 `PATCH /api/documents/{id}/review/items/{itemId}`。
- **分析备忘录**：正文区顶部切换到「分析备忘录」标签，按文档记录分析想法并把正文标注**关联为证据**——
  - **标题 + 正文**随时保存；左列分「在办备忘录 / 已归档」两个分区，在办可归档（转只读、可恢复），备忘录可永久删除（连同证据关联）；
  - **关联证据**：从本篇已有标注中勾选，关联瞬间后端对**编码名、编码色、半开区间、原文摘录**做快照（`memo_evidences` 表）；之后原标注被修改（改编码 / 改区间）或被删除（含编码删除级联），证据卡片始终展示**关联时快照**并标示**当前有效 / 原标注已变化 / 原标注已删除**；已变化时同时展示当前编码、区间与摘录并可按当前位置「定位正文」，已删除时快照完整保留、不随删除丢失；
  - 备忘录、证据与时间戳均持久化在 SQLite，刷新、重启不丢失。
  - 对应 `GET/POST /api/documents/{id}/memos`、`GET/PATCH/DELETE /api/documents/{id}/memos/{memoId}` 与 `POST/DELETE …/memos/{memoId}/evidences`。
- **备忘录 Markdown 下载**：备忘录详情行点击「下载 Markdown」（在办与已归档均可），下载单条备忘录——
  - **正文保留原文**：整体放入按内容动态加长的代码围栏，正文中的标题井号、表格竖线、反引号围栏等字符原样可见，不会破坏文档结构；
  - **证据逐条列出**：每条证据含关联时保存的**编码名、区间 `[start, end)`、原文摘录快照**与**当前有效 / 已变化 / 已删除**状态及关联时间；**已变化**时追加当前编码、当前区间与当前原文摘录；**已删除**时仅展示快照并注明原标注已删除、快照未丢失；
  - 所有用户内容（标题、文档名、编码名、摘录）均经行内转义（反斜杠 / 反引号 / 竖线 / 换行）或代码围栏隔离，无法伪造标题、代码围栏或表格结构。
  - 对应 `GET /api/documents/{id}/memos/{memoId}/export`（`text/markdown` 附件下载）。
- **持久化**：所有文档、编码本、标注、抽样复核批次与分析备忘录（含证据快照）均存于 SQLite，刷新页面后原样恢复；首次启动自动载入一份示例访谈与编码。

## 本地开发（不用 Docker）

```bash
# 后端（Python 3.11+）
cd backend
pip install -r requirements.txt
DB_PATH=./dev.db uvicorn app.main:app --reload --port 8000

# 前端（Node 20+），Vite 已配置 /api 代理到 8000
cd frontend
npm install
npm run dev   # http://localhost:5173
```

## API 概览

| 方法 | 路径 | 说明 |
| --- | --- | --- |
| GET | `/api/documents` | 文档列表 |
| POST | `/api/documents` | 新建文档 `{title, content}` |
| GET | `/api/documents/{id}` | 文档详情（含编码本与全部标注） |
| GET | `/api/documents/{id}/search?query=…` | 字面关键词检索：返回全部命中的半开区间与前后文（含彼此重叠的命中） |
| GET | `/api/documents/{id}/cooccurrence` | 编码两两共现统计，可带 `?codes=1&codes=2` 按编码筛选；返回每对编码合并后的共现字符数、片段数与原文摘录 |
| GET | `/api/documents/{id}/speakers` | 说话人分析：解析「说话人：」发言段落，返回每位说话人（含未标注说话人）的文本长度、各编码覆盖字符数与覆盖率及片段摘录；`?codes=1,2` 按编码筛选（逗号分隔，缺省为全部编码） |
| GET | `/api/code-distribution` | 跨文档编码分布对比：全部文档按所选编码汇总标注字符数、段数与占文档长度比例（文档按标题稳定排序，含行内差异百分比与首个片段），单一快照返回缺失编码与空文档提示；`?codes=1,2` 按编码筛选（逗号分隔，缺省为全部编码） |
| GET | `/api/documents/{id}/gaps` | 覆盖缺口：合并所选编码重叠/相邻的标注区间后求全文补集，返回未覆盖区间的起止位置、长度与原文摘录（保留文首/文尾/零标注场景）及覆盖率；`?codes=1,2` 按编码筛选（逗号分隔，缺省为全部编码） |
| GET | `/api/documents/{id}/transitions` | 编码流转：全部标注边界切成原子区间并以覆盖编码集合表示状态，跳过无编码区间、合并相邻同状态区间后统计相邻状态的有向转移，返回每次转移的来源、目标区间、中间距离与原文摘录；`?codes=1,2` 按编码筛选（逗号分隔，缺省为全部编码） |
| GET | `/api/documents/{id}/export` | 导出 JSON（附件下载，含 sha256 内容指纹） |
| POST | `/api/documents/{id}/import/preview` | 标注包导入预检（不落库）：请求体 `{package: <导出 JSON>}`；按编码名称映射编码本，校验内容指纹 / 区间边界 / 原文切片 / 重复项，返回新增、跳过、未知编码、非法条目明细与新增项冲突明细 |
| POST | `/api/documents/{id}/import` | 确认导入：单事务重跑全部校验，任一失败整批回滚（422，不落库）；仅写入新增标注（keep 共存），完全相同项跳过，返回新增 / 跳过明细与最新标注列表 |
| POST | `/api/documents/{id}/migration/preview` | 文档版本迁移预检（不落库）：请求体 `{new_content}`；按字符级差异把旧标注分为保留（唯一匹配自动定位）/ 待确认（多重匹配候选、内容改动建议、文本删除锚点，均附新旧上下文）/ 失配（替换后新文本），返回分类明细与原文内容指纹 |
| POST | `/api/documents/{id}/migration/commit` | 确认迁移：请求体 `{old_fingerprint, new_content, decisions:[{coding_id, action: discard\|remap, start?, end?}]}`；校验原文指纹与全部待确认决策及区间，单事务更新正文与全部标注，任一失败整批回滚（422，不落库），返回保留 / 重指定 / 放弃 / 失配丢弃计数与最新标注列表 |
| GET | `/api/documents/{id}/review` | 获取标注抽样复核批次（含抽样设置、逐条状态/备注、原文上下文、待处理/通过/需修订计数）；尚未生成时返回 `{batch: null}`；批次在文档或标注变化后返回 `stale: true` 及 `stale_reasons`（`document_changed` / `codings_changed`） |
| POST | `/api/documents/{id}/review` | 生成抽样批次（替换该文档旧批次及全部结论）：请求体 `{codes:[{code_id, sample_size}…]}`；按 `sha256(文档指纹|编码id|标注id)` 稳定排序各取前 N 条，数量超过该编码标注数时取全部；编码不存在返回 404，编码在当前文档无标注（sample_size>0）或重复出现返回 422；返回完整批次 |
| PATCH | `/api/documents/{id}/review/items/{itemId}` | 标记单条复核结论：请求体 `{status: pending\|approved\|revision, note}`；通过/需修订记录处理时间，pending 清空处理时间；批次已过期返回 409，条目不存在或不属于该文档返回 404；返回完整批次 |
| DELETE | `/api/documents/{id}/review` | 丢弃当前文档的抽样批次及全部复核结论（204） |
| GET | `/api/documents/{id}/memos?status=active\|archived\|all` | 列出备忘录（含逐条证据快照及实时状态 current / changed / missing，已变化时附 `current` 当前编码·区间·摘录） |
| POST | `/api/documents/{id}/memos` | 创建备忘录 `{title, body?, coding_ids?}`，可同时关联证据（关联时落快照） |
| GET / PATCH / DELETE | `/api/documents/{id}/memos/{memoId}` | 单条备忘录详情 / 编辑标题正文或归档恢复 / 永久删除（级联删除证据关联） |
| POST / DELETE | `/api/documents/{id}/memos/{memoId}/evidences[/{evidenceId}]` | 追加证据（去重，任一标注不存在或不属于本文档返回 422 整批不写入）/ 移除单条证据关联（不影响原标注） |
| GET | `/api/documents/{id}/memos/{memoId}/export` | 单条备忘录 Markdown 附件下载：正文代码围栏保留原文；证据逐条含快照编码名·区间·摘录及当前状态，已变化附当前信息，已删除保留快照（`text/markdown`） |
| GET / POST | `/api/codes` | 编码本列表 / 新建（重名返回 409） |
| PUT / DELETE | `/api/codes/{id}` | 重命名、改色 / 删除（级联删除标注） |
| POST | `/api/codings/preview` | 冲突预览 `{document_id, code_id, start, end, exclude_id?}` |
| POST | `/api/codings` | 创建标注，可带 `resolution: keep\|merge\|split` |
| POST | `/api/codings/batch` | 批量创建 `{document_id, code_id, items:[{start,end}…]}`：单事务校验全部区间，任一非法整批回滚（422）；完全相同的既有标注记为跳过，其余按 keep 写入；返回新增与跳过明细 |
| PUT / DELETE | `/api/codings/{id}` | 修改（同样支持 resolution）/ 删除 |
